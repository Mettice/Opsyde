**Tools Demonstrated:** Web Search, URL Reader, Python Processing, Calculator  

## 🚀 How to Run the Demo

### Step 1: Load the Template
1. Open CrewBuilder application
2. Click "New Flow" → "Templates"
3. Search for "HolidayPirates" or look for the 🏴‍☠️ icon
4. Click "Apply Template"

### Step 2: Configure API Keys (BYOK System)
The template uses your own API keys (BYOK = Bring Your Own Key):
- **OpenAI API Key:** Required for all agents
- **Perplexity API Key:** Optional (for enhanced search)

### Step 3: Customize Input (Optional)
Default focus: "European city breaks and Mediterranean beach destinations for budget-conscious travelers"

You can modify this to any travel focus area.

### Step 4: Run the Workflow
Click "Execute Workflow" and watch the magic happen!

## 🔄 Workflow Stages

### Stage 1: Travel Trend Analysis (30-45 seconds)
**Agent:** Travel Trend Analyst  
**Action:** Analyzes current travel trends and seasonal patterns  
**Output:** Top 5 trending destinations + optimal booking windows  

### Stage 2: Deal Discovery (45-60 seconds)
**Agent:** Deal Discovery Crawler  
**Action:** Searches for current deals based on trend insights  
**Output:** Structured dataset of current travel deals with pricing  

### Stage 3: Data Processing (30-45 seconds)
**Agent:** Data Processing Specialist  
**Action:** Normalizes data, calculates savings percentages  
**Output:** Clean dataset ready for integration  

### Stage 4: Content Creation (30-45 seconds)
**Agent:** Deal Content Creator  
**Action:** Generates compelling marketing copy  
**Output:** Publication-ready content with headlines and descriptions
